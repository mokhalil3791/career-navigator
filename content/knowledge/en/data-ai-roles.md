This card is written by the Career Navigator maintainers from workshop material. It is practical advice, not official guidance.

**Common titles.** Data Analyst, Data Engineer, Data Scientist, AI Engineer, MLOps Engineer, Platform or Cloud Engineer, and Product Owner. The same work can have different titles at different employers. Read the tasks, not only the title.

**Reading an advert in four steps:**

1. **Split must-haves from nice-to-haves.** Words like “is a plus”, “preferred” or “pré” mean nice to have.
2. **Note the Dutch-language demand** separately (see the card “Dutch language at work”).
3. **Turn tasks into requirements.** “You build weekly dashboards” means: data cleaning, a dashboard tool and explaining results.
4. **Match each requirement to evidence** you can show: a project, a task in a previous job, or a course result you can explain.

**Example (fictional):** the advert says “SQL is a must, Python is a plus”. If your profile shows six saved SQL queries from a personal project, mark SQL as *Supported* with that evidence. If Python is not in your profile, mark it *Not shown* and add a next step, for example “Write one small script that checks a CSV file.”

**English-friendly roles.** Some data and AI teams work in English, especially in larger and international organisations. Always check the advert, and ask when it is not stated.
