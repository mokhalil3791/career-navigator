# Code of conduct

Career Navigator is built for and with people who are starting a new life and career in the Netherlands.

- Be kind and patient. Many contributors are learning to code, or learning English or Dutch.
- No stereotypes about any culture, country, religion or group, including Dutch culture.
- Never ask anyone for, or post, personal details: residence status, documents, BSN, address, health.
- Disagree about ideas, not people.

Report problems to the maintainer through a private GitHub message to @mokhalil3791.
The maintainer may remove content or block accounts that break these rules.
This code is adapted in spirit from the Contributor Covenant 2.1.
